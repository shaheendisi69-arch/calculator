# OOP Java Calculator

A console-based calculator built using Object-Oriented Programming (OOP) principles in Java.

## Features
- Addition, Subtraction, Multiplication, and Division
- Clean OOP architecture with inheritance and interfaces/abstract classes

## How to Run

1. Clone the repository or download the `.java` files.
2. Compile all files in your terminal:
   ```bash
   javac *.java
   java com.ttbb.myfirsttry.MyFirstTry
   ```
